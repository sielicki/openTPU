Projection certificate obligations
----------------------------------
Pin the actual Yosys executable and its exact acquired source/build linkage,
kernel/satgen.cc and kernel/satgen.h. Do not reuse the old MXU model snippet:
the currently acquired source has different code organization. Extract/authenticate
the exact mux, pmux and pos/buf branches, importSigSpecWorker, importDefSigSpec,
importUndefSigSpec, extendSignalWidthUnary and undefGating. Changed implementation
must fail closed until reviewed, even if cell names remain the same.

The justification is coordinate projection of the ACTUAL explicit-undef SAT
relation, including intermediate value variables, not merely Verilog two-state
functional equivalence:
* mux value and undef equations act per coordinate with the same imported S.
* pmux value is the same ordered selector fold for each retained coordinate;
  undef includes the same global unknown-selector and multiple-active-selector
  conditions across ALL branches. No exclusivity assumption is introduced.
* exact equal-width buf has no extension/truncation. Each retained output keeps
  its separate value/undef variables and coordinate undefGating equation.
* undefGating allows an undefined output value to vary independently. It is
  retained, not replaced with an alias equation.
* importDefSigSpec creates a fresh value for each literal-X occurrence, but
  wire identities share named variables. S is imported once per retained cell.
  Keep every retained data occurrence and its port/coordinate provenance;
  map its existential value to the corresponding original occurrence. Removed
  data occurrences do not occur in retained-coordinate equations. Literal Z
  retains the actual installed model treatment; do not relabel it X or zero.

An executable small certificate suite should instantiate actual primitive cells
with separated outputs and exercise all binary/undefined selectors, repeated
wire data, literal-X occurrences, arbitrary undefined output values and pmux
multi-active selection. Compare projected relation against elimination of only
omitted coordinate variables, not equality of independently chosen undefined
output values. Tiny exhaustive value/undef relation enumeration can validate
the certificate formulas, but does not replace the pinned-source coordinate
argument. Use demonstrably wrong branch-coordinate indexing and unknown-buffer
aliasing negatives. Do not presume selector cloning changes observable behavior:
the pinned mux/pmux undef rules can mask that difference. Keep the one-owner,
one-selector-import provenance check independently. No generic compiler/kernel
theorem is claimed.
