----------------------------------

Four-state detail requiring care
--------------------------------
Existing ABI simplifies the return predicate using vpos[24] && !out_v, where
out_v=vpos[24]&&fin. This is equivalent in two-state logic but not universally
four-state: vpos24=X,fin=1 yields original lp_v&&!fin=0, simplified=X.
The proposed core computes exact fin and uses original expression. Do not claim
unchanged arbitrary-X standalone-ABI behavior; this is a deliberate correction to
match original. Full datapath four-state equivalence is not inferred from it.
Use logical !=, not !==; unknown predicate in procedural if does not fire.
Simultaneous fatal conditions can race across always processes; tests must isolate
each predicate or accept the exact set of triggered messages, not invent ordering.
