---------------------------------------------------------------------------

For every actual cell eligible for sharing:

- Output vector widths/index order must agree. Replace the duplicate output
  coordinates by the canonical cell's corresponding output IDs throughout all
  consumers and observed vectors. Retain one actual cell implementation. Create

- Record original cell identities, complete type/parameter/input/output signature,

Conservative initial whitelist candidates (require source/model audit first):
bitwise not/and/or/xor/xnor, fully defined mux, finite-width add/sub/mul, ordinary
comparisons/reductions/logical ops. Case equality can be deterministic when ALL
operands are structurally defined, but it is unnecessary to start with it and
must never be admitted based on output totality alone. $shiftx, division/modulo,
pmux with unrestricted select, formal/nondeterministic cells, unknown primitives,
and ANY X-bearing dependency remain unshared initially. Even a total observed
output does not imply every internal arithmetic cell is eligible.

Why safe: by induction from shared binary roots, two eligible exact signatures
compute the same total vector under every input assignment. Replacing one by the
other is a deterministic expression substitution. Since all replaced outputs are
defined in the explicit-undef model, merging them cannot correlate independent
unknown choices or conceal a mismatch. Noneligible internals and all explicit-X
branches stay side-disjoint. Definedness of final observations remains the prior
separate complete premise; it is not used to justify arbitrary internal merging.
