The harness has impossible=constant0. Exact definedness query:
  sat -enable_undef -set-def-inputs -set-any-undef observed -prove impossible 1 -verify -show-inputs -show-outputs -dump_json definedness-counterexample.json

This is intentionally an UNSAT query: if any observed bit can be undefined,
there exists a counterexample to impossible==1. Success therefore proves that
no observed bit can be undefined under arbitrary defined external/current-state
inputs. It does NOT assume outputs defined. The only premise is defined public
inputs, including shared current state and parent boundary state, as required
by the two-state initialized product. No sampled-reset/fill/traffic assumptions.

Then prove step_ok, output_ok, observer_ok individually with:
  sat -enable_undef -set-def-inputs -prove PROPERTY 1 -verify ...
