Resource findings
-----------------
Partitioning24427 outputs into32-bit slices bounds selected roots, not cone size.
Index.cone follows every input of each encountered cell. A single bit of a wide
vector mux can therefore pull the entire bank of sibling datapaths into a cone.
The writer retains every output and WIDTH of that mux, so merely traversing precise
bit dependencies while still emitting its original full cell is insufficient:
it either leaves dependencies undriven or still imports the giant cell. SQLite's
8MiB cache controls graph storage, not Yosys/SAT size. Paired equality includes two
cones and undef tracking, potentially increasing solver memory over one-side probes.
There is currently no projected bit-width budget/preflight or adaptive partition
refinement in check_streamlane_parent_cones.py. A fixed32-bit plan can still OOM.
Streamlane lacks certified omitted Q entirely: all18982 bits are mapped. Do not
copy MXU's undriven omitted-state allowance or add any internal cut to reduce size.
