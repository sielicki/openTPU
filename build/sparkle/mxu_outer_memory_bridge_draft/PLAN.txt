Semantic argument and applicability boundary
The domain is an explicitly stated discrete collected-memory value/undef
clock-step relation with defined fullQ and defined external inputs/RAM/FP
returns. Simlib supports its four-state coordinate equations; it does not prove
this lifted value-correlation model or source SV/event-region equivalence.
Certified defined RD_ADDR and WR_EN make each actual read address/enable choice
known. In-range reads select the same defined existing wordQ. Out-of-range reads
remain X: one shared original RD wire carries its value/undef pair to every
consumer, and the exact mux tree preserves an unconstrained value with undef1
for that wire. Do not independently choose values for different consumers.
Known disabled writes retain Q; known enabled writes select actual WR_DATA,
including its undefinedness. Distinct constant write addresses remove priority
ambiguity. Complete fullD totality then establishes all nextQ defined in this
domain; it does not establish every internal node or public output defined.
Every coherent assignment of this source relation extends to the added muxes
while preserving every original wire. Each already chosen undefined original
RD value is admissible at its tree output under exact SatGen undefGating.
Additional correlations between source OOB choices can therefore be retained;
no independent choice is forced and no source value is reselected. The reverse
model inclusion and raw value/undef model identity are not claimed. No equality
of raw unknown-selected mux value correlations is assumed. This intermediate
model certificate does not discharge the final original-source parity goal.
